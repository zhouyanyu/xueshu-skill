# xueshu：学术精读与论证 Wiki

面向理论著作、逻辑教材、历史研究与解释性社科读物的中文阅读技能。把书籍整理成可回查的原文、逐章笔记、概念与论证专题以及全书问题地图，支持持续阅读、难段解释和跨章研究。

## 适用书籍与阅读模式

| 模式 | 重点 | 示例 |
|---|---|---|
| 理论与概念 | 概念依赖、范畴转换、抽象层次和理论推导 | 《资本论》 |
| 形式推理与教材 | 符号、定义、推理规则、证明与反例 | 《逻辑学导论》 |
| 历史解释与研究 | 问题意识、史料使用、因果解释和政策评价 | 《大外交》及历史学术专著 |
| 模型与通俗解释 | 假设、机制、寓言映射和现实适用边界 | 《小岛经济学》 |

示例说明适用方向，不代表仓库包含这些书籍或已完成对应精读。同书或同章可混合模式，不按书名机械分类。

## 安装

在 Codex 技能目录下安装为 `xueshu`。Windows PowerShell 示例（系统已安装 Git 和 Windows OpenSSH）：

```powershell
$taskSkillRoot = Join-Path $env:USERPROFILE '.codex\skills'
New-Item -ItemType Directory -Path $taskSkillRoot -Force | Out-Null
git -c 'core.sshCommand=C:/Windows/System32/OpenSSH/ssh.exe -o BatchMode=yes -o ConnectTimeout=15' clone 'git@github.com:zhouyanyu/xueshu.git' (Join-Path $taskSkillRoot 'xueshu')
```

若目录已存在，先检查其内容，不覆盖现有定制。SSH 克隆需要已配置可访问 GitHub 的密钥及正常主机校验。技能检查器仅依赖 Python 3.9+ 标准库；正文解析使用执行环境已有工具，扫描 PDF 可能需要 OCR。没有全文、扫描文本不可靠或公式丢失时会记录范围限制。

## 使用

提供 EPUB、PDF、DOCX、HTML、Markdown 或文本文件，然后输入：

> 使用 `$xueshu` 整理这本书。

默认整理全部可读正文及有实质内容的注释、附录，连续分批保存；无需逐批确认。范围只含上传的材料。单章、预览或解释请求覆盖全书默认值，例如：

> 使用 `$xueshu` 精读第三章，重点解释各概念怎样支持作者结论。

> 使用 `$xueshu` 解释这段证明，保留符号、前提和每一步使用的规则。

> 使用 `$xueshu` 分析这章史料如何支持作者解释，区分史料记载与作者判断。

> 使用 `$xueshu` 帮我接着读，根据已有 Wiki 回顾当前问题和必要概念。

只有书名时可以介绍已知思想，但不能代替该版本原文精读。问一个窄问题不会自动生成整套 Wiki；普通问答默认不保存，要求加入已有档案时再保存。

## 工作流程

1. 确认书名、作者、译者、版本、实际目录及请求范围。
2. 解析正文，保留有用注释与来源映射，建立稳定段落锚点。
3. 按章和原小节精读，说明问题、概念、前提、推理、证据及结论条件。
4. 汇总跨章概念与重要论证；根据实际需求增加图、表和公式。
5. 更新阅读首页及覆盖记录，分别记录读者、提取、精读与综合进度。
6. 检查链接、来源锚点和覆盖结构，再人工核对内容；交付首页和真实覆盖范围。

作者观点、引用材料、助手解释、外部研究和用户批注分层保留。隐含前提、教学例子和重建证明明确标识；不会把助手补充说成作者原话。外部查证围绕具体疑点进行，不能取代原书精读。

## 输出与接续

默认沿用指定或既有书籍档案。否则保存到当前任务用户交付目录的 `学术Wiki/书名-版本/`，没有交付目录则使用工作区。

```text
学术Wiki/书名-版本/
├── 阅读首页.md
├── coverage.json
├── 章节笔记/
├── 原文/
├── 概念索引.md                 按需
├── 全书问题与论证地图.md       按需
├── 专题/                      按需
└── 阅读进度.md                按需
```

每章保留原文定位、问题推进、重要概念与论证。简单概念集中索引，复杂概念和跨章论证再拆页。无固定图数；概念依赖、机制、比较、证据对应及形式证明使用合适表达。

中断会保存已完成范围和下一续接点；提取全文不等于精读全书。默认可用已核实后文解释当前章并单列后文来源；要求按读者进度阅读时过滤后文。

## 与 xiaoshuo、lishi 的分工

- xiaoshuo：人物、场景、情节、因果与线索。
- lishi：史料、史事、人物、制度与文化档案。
- xueshu：问题、概念、论证、证据与模型。

《明代士大夫的精神世界》《康熙的红票》等，重点理解历史内容时优先 lishi；重点分析作者论证和研究方法时使用 xueshu。已有同书 Wiki 时补充相关专题，避免建立两套重复档案。执行本技能不依赖安装另两个技能。

## 覆盖与链接检查

在有 Python 的终端执行：

```powershell
python .\scripts\check_wiki.py 'C:\你的书籍Wiki目录'
python .\scripts\check_wiki.py 'C:\你的书籍Wiki目录' --require-complete
```

第一条允许明确登记的未完成单元；第二条用于全书完成交付。覆盖记录格式见 [Wiki维护](references/wiki.md)。脚本检查非空首页、单元ID、文件、段落锚点、覆盖区间及标准内联 Markdown 链接。它不证明精读充分、引文真实、原书目录完整或论证正确；双链、引用式链接及 Mermaid 渲染仍需人工检查。

维护者可运行 `python .\scripts\validate_checker.py` 验证检查器；12 项测试覆盖完整／部分精读、段落缺口、重复ID、来源缺失、断链及代码块中的示例链接。测试只创建临时材料，不代表真实整书试读。
