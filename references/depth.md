# 讲解深度与延伸

## 深度的判断

本 skill 的精读是“帮助读者学会原书知识”，不是把目录、摘要、引文和图片装进 Wiki。可回查是必要条件，不是讲解本身。读者应当能从笔记理解本章主要内容，再按链接核实原文，而不是必须重读大段原文才能知道笔记在说什么。

深度随内容变化：一个定义可能需要辨析，一个形式推理需要逐步证明，一个历史解释需要材料与判断之间的桥梁，一个经济模型需要机制与条件。不要给所有书加同样数量的栏目和无关知识。

## 怎样展开一个知识单元

围绕实际问题组织连续讲解，通常包含下列有用环节；不要求每个段组都重复同一套标题。

1. **具体主张**：作者说了什么，针对什么问题或旧解释。不是“讨论了X”，而是讲明对X作出了什么判断。
2. **概念与材料**：关键术语在此处是什么意思；故事、史料、数据或符号具体提供了什么信息。原书例子要说明其结构及作用，不能只留名字或图片。
3. **推理或机制**：从前提到结果，逐步说明发生了什么变化、为什么变化、靠什么材料支持。对缺少的前置知识就地补讲。
4. **帮助理解的演示**：换一个条件清楚的小例子、计算、类比、反例或材料对读，说明它如何验证理解。助手例子与原书例子区分。
5. **回到问题**：解释成立依赖什么条件、解决了什么，留下什么未解决。延伸最终必须回扣本章。

对本章每条主要论证都讲到可复述，不把讲解全部外移到“专题另见”。专题可保存更广比较，本章仍应包含读懂本章所必需的内容。

## 主动延伸的边界

实质章节默认包含围绕核心问题的延伸，不必等待用户点名。选择能解决具体理解困难的方向并展开，不堆术语和百科材料：

- **补前置知识**：解释原书略写的概念或方法，展示它怎样用于当前论证。
- **换例子与迁移**：用条件明确的教学场景说明怎样运用本章知识，检查读者是否只记住故事。
- **改假设**：改变一个关键条件，推演哪一步受影响，哪些结论仍成立。不能只说“有局限”。
- **作比较**：与相近概念或另一种解释对照，指出分歧落在定义、假设、机制、材料还是价值判断。外部理论若无法可靠归属，不凭记忆杜撰学者引文。
- **辨现实适用性**：说明模型映射到现实需增加什么条件；涉及实际事件、数据及经验主张时给可靠来源。纯教学例子不得写成现实已验证事实。

明确区分原书内容、助手教学解释和外部研究；可以用小标题或就近说明，不必每句加冗长标签。没有联网也能解释原理、做条件推演和自拟例子；真正需要证据的具体事实单列待查。延伸应帮助理解，不能把原书换成助手自己的理论讲义。

## 浅笔记与展开示范

以下均为自拟教学材料，不是任何书的引文、摘要或数据。它们示范解释密度，不是每章必须套用的答案。

### 理论：区分原因与认识依据

浅写：“作者区分原因和理由，二者不同。”

展开：“原因解释某件事如何发生；认识依据说明我们凭什么相信某个判断。路面湿了，可以作为刚下雨的判断依据，但湿路面并不是下雨的原因，洒水车也能产生湿路面。因而从观察到现象到认定其原因，还要排除其他解释。”如果原书的‘理由’采用规范或行动语境，必须按该语境重讲，不能把这个示例当通用定义。

### 形式推理：一个反例为何足够

浅写：“肯定后件无效。”

展开：“从 P→Q 和 Q 推 P 无效。令 P 为假、Q 为真，P→Q 与 Q 两个前提都真，结论 P 却假，已经满足无效推理的反例条件。‘下雨则路湿，路湿，所以下雨’可由洒水造成路湿来理解。延伸比较：若增加 Q→P，就可以从 Q 推 P；缺少的是必要的反向关系，而不是少写一句‘显然’。”

### 历史研究：记载不能直接证明普遍性

浅写：“材料有立场，需谨慎使用。”

展开：“假设研究只使用某群体为公开发表而写的文集，它能直接支持的首先是这个群体选择怎样表达自身。要进一步说这种观念普遍存在，还需要解释样本代表性、写作场合和是否有其他实践材料印证。延伸时可比较私信与公开文章是否面向不同受众；即使内容不同，也要考虑时间和场合，不能直接断言作者虚伪。”真实著作须具体指出作者使用了什么材料，不用这一段替代史料分析。

### 模型：储备怎样支持一次生产改进

浅写：“储蓄促进投资，投资提高生产率。”

展开：“设一人每天捕2单位食物、消费1单位；连续4天可积累4单位。若工具制作需停工3天且无其他开销，这些储备足以维持制作期消费。这一机制把‘储蓄’落实为等待期间可用的实际资源。再假设工具制成后日产量升到4单位，比较的是相同劳动日的产出；增产取决于工具成功，不能仅由储备自动推出。若制作期变为5天、食物中途腐坏或工具失败，储备约束与风险会改变可行性。此处只演示资源和时间约束，不能由此直接断言现代银行贷款必须先有等额存款，或推出所有宏观政策判断。”

## 交付前的内容验收

对每个实质章节检查：

- 去掉原文引述、图片、图表和链接后，是否仍能理解章节主要知识？
- 能否说清关键概念的含义与区别，而非只能记住几个术语？
- 能否从前提、材料或初始条件复述主要推理，缺失步骤是否被标明？
- 是否有围绕核心问题展开的延伸，确实增加理解，而不是一句提醒或链接？
- 每个主要小节、独立论点及关键例子是否得到对应讲解，是否用一条概述覆盖太多不同内容？
- 是否区分作者论证、教学补充和外部事实？图是否被解释、引文是否被分析？

失败时补写具体讲解；不能用增加引文、图数、字数或“已精读”的声明补救。延伸不适用的非知识性材料按实际内容说明即可，不制造批评。

脚本只负责结构检查。内容验收由实际回读执行，不把 JSON 字段、关键词或长度阈值当成深度证明。既有档案即使标为 completed，若只有摘要或素材，也应说明需要深化；用户要求修订既有笔记时再回读原文并逐章补足，不自动批量改写用户档案。
