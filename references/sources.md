# 原文提取与定位

## 识别材料

记录文件、书名、作者、译者、版次／出版信息、格式与实际目录。章、节与文件不一定一一对应，使用真实目录和正文标题确认。注释及附录单列，并说明是否纳入本次请求。

EPUB 按 `META-INF/container.xml` 定位 OPF，读取 metadata、manifest、spine，结合 nav／NCX 确认阅读顺序。不要按 ZIP 文件名排序；跨文件章节合并，同文件多章拆分，脚注保留与正文的对应关系且不重复提取为正文。加密或损坏时记录具体阻碍，处理可读部分。

PDF 优先提取文本；扫描页需要 OCR，公式、表格、脚注和栏序人工抽查。不将乱码或缺失公式当完整正文。印刷页码与 PDF 页序分开标注；EPUB 不伪造固定页码。DOCX、HTML、Markdown、文本按真实标题和阅读顺序解析，优先使用环境已有工具。

## 稳定定位

每个阅读单元保存一个 UTF-8 Markdown 原文文件，路径如 `原文/u001.md`。保留原章名、小节、段落及有用注释；给实际段落按顺序添加显式 HTML 锚点：

```markdown
# 第一章 原章名

<a id="p0001"></a>
原文第一段……

<a id="p0002"></a>
原文第二段……
```

笔记使用标准相对 Markdown 链接，如 `[原文第2段](../原文/u001.md#p0002)`。分段笔记给起止锚点；引文、关键概念定义、重要数字和争议尽量给具体段落。已有稳定定位方案可沿用，但须相应调整检查方式并说明。

锚点初次提取后保持稳定，不因改笔记重新编号。修复提取需变更段号时更新所有引用，记录变更，不在不知情的情况下迁移旧锚点。脚注分配独立标识，并登记于覆盖记录的 `extra_anchors`；不能覆盖正文段号。

保存原文映射信息：EPUB 内部路径／正文标题，PDF 页序范围及可靠的印刷页码等。拼接多个位置的引文注明省略与各出处；原文不可用时只能说“据已有笔记／本书引述”。外部资料另列作者、题名、日期、URL或实际文献定位。

版本不同分别记录，不机械套用另一译本的页码。长书批量提取后再按单元实际读取；可定位全文并不代表精读完成。
