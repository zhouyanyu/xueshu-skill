# 精读与专题模板

按实际文本选用，省略不适用的栏目，不用空白占位撑档案。

## 章节精读

```markdown
# 第X章 原章名

[返回阅读首页](../阅读首页.md)

## 来源与范围
作者、译者、版本；本章实际段落范围；原文入口。

## 本章在解决什么
核心问题、本章在全书的位置、理解所需前置概念。

## 按原文顺序精读
### 原小节标题或段组主题
原文起止锚点；本段的主张、概念及论证推进。
关键引文或准确转述；难点解释；证据的性质及用途。

## 关键概念与论证
主要概念链接；重要论证的前提、步骤与结论。
已在分段中解释清楚的内容用定位链接，不重复抄写。

## 条件、争议与待核对事项
范围限制、隐含假设、文本疑点及确有依据的分歧。

## 接着读需要记住什么
少量核心结论、未解决问题、下一章入口。
```

复杂章按小节保留多条论证，不强行归为一个中心论点。描述性章可以说明它为后面提供什么材料，不强造待证明结论。公式、数据、独立观点不能全部压缩成“作者进行了讨论”。

## 概念索引与独立页

索引集中记录概念、作者定义／用法、关键出处、相关概念。别名和译名确认后统一；跨作者的同名概念分列。概念有多处定义、重要变化或跨章论证作用时可拆页，包含：

- 作者怎样定义，定义的对象和条件是什么。
- 本书中怎样演变，在哪里被使用。
- 与容易混淆的概念怎样区别。
- 一个有来源的原书例子；助手另举例子则注明。
- 关键出处及关联论证。

概念图中的每条依赖都应能说明依据。并列出现不代表相互依赖。

## 论证专题

为跨章持续推进或值得单独回查的论证建页：

1. 要回答的问题与准确结论。
2. 明确前提及性质：定义、假设、经验材料等。
3. 论证步骤，逐步链接原文；助手重建部分明确标识。
4. 证据与步骤的对应关系。
5. 适用条件、作者回应的异议、具体未解决问题。
6. 各章提供了什么，哪些解释来自外部资料。

不要把“有效／无效”标签强套在历史解释和理论叙述上；对应采用材料支持程度、解释范围和替代解释。形式推理则依其逻辑系统检查有效性。

## 全书问题地图与回顾

从已精读章节汇总：总问题、章节作用、主要概念依赖、主论证链、结论及边界。标注未精读章节，不按目录猜论证。简短回顾可以“每章一句话＋关键概念＋关键论证”；它是导航，不能替代底层精读。

比较两书时先确定共同问题，再分别列概念定义、分析对象、假设、材料与结论；不可因使用同一词就直接比较，更不能以引用数量判断谁更可靠。
